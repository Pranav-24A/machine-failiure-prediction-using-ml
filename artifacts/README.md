# Artifacts Directory
This directory stores generated evaluation metrics, model comparison reports, feature importance scores, and confusion matrix data:
- `evaluation_metrics.json`: Detailed test & validation metrics (Accuracy, Precision, Recall, F1, ROC-AUC, PR-AUC).
- `model_comparison.json`: Comparison table across all evaluated algorithms (Dummy, Logistic Regression, Random Forest, HistGradientBoosting).
- `feature_importance.json`: Global feature importance coefficients/scores.
- `confusion_matrix.json`: Test set confusion matrix counts.
- `failure_mode_metrics.json`: Per-failure-mode evaluation metrics.
