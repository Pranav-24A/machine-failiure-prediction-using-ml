# Trained Models Directory
This directory stores serialized models and fitted transformers:
- `failure_classifier.joblib`: Primary binary classification model for machine failure prediction.
- `failure_mode_classifier.joblib`: Multi-label or multi-output model for predicting specific failure modes (TWF, HDF, PWF, OSF, RNF).
- `preprocessing_pipeline.joblib`: Fitted Scikit-Learn preprocessing pipeline (encoders, scalers).
